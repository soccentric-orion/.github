# Orion

Open-source embedded Linux platform for **STMicroelectronics STM32MP1**, from [SoCcentric](https://github.com/Soccentric).
MIT licensed.

| Repository | Purpose |
|---|---|
| [Orion-OS](https://github.com/soccentric-orion/Orion-OS) | Yocto/kas image build |
| [meta-orion](https://github.com/soccentric-orion/meta-orion) | Yocto layer for the board |
| [Orion-HAL](https://github.com/soccentric-orion/Orion-HAL) | Hardware abstraction layer (C++17) |
| [Orion-Client](https://github.com/soccentric-orion/Orion-Client) | gRPC client (C++17) |
| [Orion-Server](https://github.com/soccentric-orion/Orion-Server) | Test server (Drogon, C++) |
| [Orion-Configuration](https://github.com/soccentric-orion/Orion-Configuration) | WebConfig on-device configuration |
| [Orion-Dashboard](https://github.com/soccentric-orion/Orion-Dashboard) | HTML5 dashboard |
| [Orion-PySDK](https://github.com/soccentric-orion/Orion-PySDK) | Python SDK |
| [Orion-Instrumentation](https://github.com/soccentric-orion/Orion-Instrumentation) | On-device management and observability |
| [Orion-HQ](https://github.com/soccentric-orion/Orion-HQ) | Fleet management |
| [Orion-Hardware](https://github.com/soccentric-orion/Orion-Hardware) | Hardware documentation |

Contributions go to the `develop` branch. See the shared [contributing guide](https://github.com/soccentric-orion/.github/blob/main/CONTRIBUTING.md).
